# 垃圾焚烧发电 · SimpleHMI 流程演示

已根据提供的流程图制作可运行工程，并录制实际软件操作视频。

## 打开运行

1. 本机已有服务时打开 http://127.0.0.1:1881/simplehmi/ 。
2. 点击 **项目 → 垃圾焚烧发电 · 流程演示 → 运行 → 启动流程**。
3. 点击设备查看参数，底部切换 **工艺全流程 / 趋势与报警**。
4. 用 **模拟炉温报警 → 复位演示报警** 演示异常和恢复；用 **停止流程** 演示参数回落。

解压 `SimpleHMI-MVP.zip`，进入 SimpleHMI 目录，macOS 双击 `Start-SimpleHMI.command`，或运行 `./start-simplehmi.sh`。首次安装需要 Node.js 与网络；包内附已有工程师界面的构建结果。当前交付目录也可直接 `npm start`。完整说明见 `SimpleHMI/README.md`。

独立工程文件 `垃圾焚烧发电.simplehmi.json` 可通过项目菜单导入。模板保持初始待机状态，导入后点击运行和启动。普通刷新保留服务中的运行状态；重新导入模板会覆盖同名工程布局，建议先导出自定义版本。

## 已实现

- 17 个设备节点、25 个变量、2 个页面、74 个组件（总览 60、趋势 14）。
- 垃圾接收、上料焚烧、余热锅炉、蒸汽发电、半干式脱酸、布袋除尘、引风排烟。
- 二次风与空气预热、烟气再循环及预热、石灰浆、活性炭、灰渣和飞灰支路。
- 原生 SVG 设备，运行状态、管道流向动画、实时参数、设备说明与参数快照。
- 启动、停止、模拟高温报警、复位；实时曲线与本次服务运行的历史缓存。
- 保留 SimpleHMI 的编辑、变量绑定、自动保存、导入/导出与 FUXA 工程师入口。

## 验证与边界

- 语法检查通过；13 项测试通过，覆盖过程启动/升温/报警/复位/停止、工程绑定一致性以及原有 FUXA 集成与 Modbus 测试从站读写。
- 浏览器实测了启动、设备详情、趋势页面、高温越限、总览报警、复位恢复、停止与再次启动。
- MP4 全片解码检查通过，并核对关键阶段画面。
- 本次垃圾焚烧流程使用明确标注的加速模拟数据，未连接现场 PLC。现有 Modbus TCP 功能可继续复用，但需要实际点表与设备地址完成映射。
- 不包含现场联锁、安全控制、排放合规判断、工业热力计算或真实启停程序。历史为运行缓存，非持久化生产历史库；设备弹窗显示点击时参数快照；流程连接线由工程 JSON 定义，尚无可视化布线工具。
- 参考图中的 4.4 MPa / 450 °C 用作演示目标，不是现场操作设定。
