# FlexHMI 0.4.1 macOS 桌面预览版

补齐原生 macOS 桌面应用，分别提供 Apple Silicon（arm64）和 Intel（x64）DMG。打开 DMG 后拖入 Applications 即可安装，无需额外安装 Node、Edge 或 Chrome。继续采用黑白中文界面，优先普通电脑上的完整桌面体验。

## 下载选择

- M 系列 Mac：FlexHMI-0.4.1-macOS-arm64.dmg
- Intel Mac：FlexHMI-0.4.1-macOS-x64.dmg

目标系统 macOS 13+；本次双架构自动安装验收运行于 macOS 15，macOS 13/14 尚未验证。具体测试版本、来源提交、文件大小和 SHA-256 见 qualification.json / SHA256SUMS.txt。

## 已执行的安装与功能验收

两个架构均从实际 DMG 复制应用到含中文、空格的安装目录后执行：原生 Node/SQLite/串口模块加载、守恒双水箱模拟读写、停止后液位保持、23 个 MCP 工具与本机服务发现、Agent 修改工程与绑定保存恢复、重复启动复用服务、原生 WebKit 编辑画面与实时数值显示、切换运行隐藏编辑器、覆盖安装、卸载保留工程。

Mac 数据独立保存在 ~/Library/Application Support/FlexHMI。关闭窗口继续运行；Command+Q 保存工程并停止本机服务。退出不会向物理设备发送停机命令。修复 macOS 路径别名导致 MCP 启动后立即退出的问题，并增加对应回归。

## 预览版边界

应用仅使用 ad-hoc 完整性签名，尚未进行 Developer ID 发布者签名或 Apple 公证。核对来源和 SHA-256 后，若系统阻止打开，可在“系统设置 → 隐私与安全”查看对应提示并选择“仍要打开”。不要关闭 Gatekeeper。

本次没有测试物理 PLC、真实串口设备、真实模型服务或生产知识库质量，不代表生产系统认证。已有 Windows 0.4.0 下载继续保留；本次 0.4.1 是 Mac 桌面交付。
