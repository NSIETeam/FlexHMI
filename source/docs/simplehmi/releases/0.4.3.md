已验证：启动与原生模块、编辑/运行画面、守恒供水模拟、工程保存重开、编辑历史恢复、步骤控制两次回读、MCP 服务端权限、撤销后暂停控制、重启保留历史和授权，以及升级和卸载保留工程。新增安装后的模型协议评估、步骤引用、无改动报告、搜索翻页、MCP 只读访问及重启恢复验证；步骤执行期间依据过期会停止后续输出。Windows 还验证中文名称、旧菜单迁移及保留无关文件。

Windows x64 在 Windows Server 2025、ARM64 在 Windows 11 验证；两种 Mac 均在 macOS 15.7.9 验证。Windows 10 / 11 x64 和 macOS 13/14 尚未直接验证。

预览版没有 Windows 发布者签名或 Apple Developer ID 签名及公证。模型使用本机协议夹具；真实模型服务、物理 PLC 和生产行业知识质量尚未完成验收；内置资料和过程数据用于演示。访问保护默认关闭，启用后需要所有者密码，Agent 使用单独授权。
