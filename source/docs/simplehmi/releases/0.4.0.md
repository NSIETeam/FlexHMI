# FlexHMI 0.4.0 工控机预览版

这是通过 Windows x64 / ARM64 自动安装与功能验收的未签名预览版，可用于本地演示和项目验证。它不是现场控制系统认证，也不表示全部产品目标已经完成。

## 下载与启动

- Intel / AMD 64 位电脑：`FlexHMI-0.4.0-IPC-Windows-x64-Setup.exe`（60,160,356 字节，约 60.2 MB）。
- Windows on ARM：`FlexHMI-0.4.0-IPC-Windows-arm64-Setup.exe`（56,215,114 字节，约 56.2 MB）。
- 需要 64 位 Windows 与 Microsoft Edge。已在 GitHub 的 Windows Server 2025 x64、Windows 11 ARM64 上运行验收；Windows 10 和客户工控机配置尚未验证。
- 下载安装器后，从开始菜单打开“编辑工程”“运行画面”或“全屏运行”。无需另装 Node.js、npm 或 MCP 扩展。内置界面与协议依赖，AI 模型服务需单独配置。
- `Payload.zip` 是开发者重建输入，不是普通用户安装包；请下载安装器 `Setup.exe`。
- 安装包没有代码签名，Windows 可能显示未知发布者。请从本发布或官网下载，并与 SHA256SUMS.txt 核对。

## 这版包含什么

- 中文黑白 FlexHMI 界面、112 个可搜索设备图形和自定义 SVG 导入。
- 原生 AI 结构化计划与影响预览；数据可视化、智能控制、行业知识评估三种工程模式。
- 内置 23 工具 MCP 接入：工程编辑、项目加载/归档恢复、实时值、历史、知识评估、控制及有约束的点位写入。真实设备输出默认关闭。
- 可点击管线的连接编辑器；起终点、端口、反向、回流、状态绑定、预览、删除与撤销。
- 循环展开、分支排序、名称避让、交叉诊断。运行流向根据新鲜 Bool 状态显示；数据失效显示未知状态。
- 双水箱守恒演示，原水箱下降、高位水箱上升，停泵保持，总水量恒定。
- 工控机版复用系统 Edge，不附带 Electron 浏览器内核。相对历史 0.2.0 的 x64 包，安装体积减少约 76%。

## 当前边界

- 未用真实模型账号验证生成质量；内置模型协议已通过测试服务验证，外部 MCP 已运行验证。
- 行业知识自带样例不是生产行业数据库。实际资料需由使用方提供来源与适用范围。
- 自动控制目前为阈值回差规则；通用状态机、多用户权限、通用回滚仍在开发。
- 没有完成真实 PLC / 物理串口设备、Windows 10、客户现场及签名分发验证。
- 关闭画面不停止采集或已授权控制；使用“停止服务”结束本机服务。停止服务不等于发送设备停机指令。重启不会自动恢复控制授权。
- 默认数据目录 `%LOCALAPPDATA%\FlexHMI-IPC`。卸载保留数据；旧 SimpleHMI 工程通过导出/导入迁移。

原 0.3.0 的交叉构建安装器存在启动崩溃，本版本改用匹配的 Windows NSIS 编译器/插件构建，并独立完成验收。请使用此版本，不使用旧候选包。
