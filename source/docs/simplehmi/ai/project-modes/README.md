# 系统类型：新建、查看和转换

现在可在“项目 → 新建工程”直接选择数据可视化、智能控制或行业 AI 系统。编辑器顶部工程名称下显示当前类型，点击可打开转换面板；“项目 → 更改类型”进入同一面板。AI 工作台的“本次生成类型”沿用当前工程类型，修改它只影响本次生成需求。

- 数据可视化：显示实时值、趋势并保留手动操作；不能启动自动控制。
- 智能控制：在已有设备、变量和画面上配置控制规则或步骤流程，检查后单独启动。
- 行业 AI：在已有工程上添加资料并配置模型，结合观测进行评估，先预览工程或控制计划，再应用。选择类型本身不会生成行业资料或模型服务。

转换先展示目标类型、保留对象的数量和关联影响，再应用。普通的类型转换保留页面、位置、绑定、设备、变量、规则、步骤流程和知识资料；已有失效引用仍按共同依赖检查停用，并显示具体影响。预览或取消不会暂停正在运行的控制；应用转换会暂停控制，不会发送设备停机指令。切回控制类型后也不会自动恢复运行授权。

修改类型选择会使旧预览失效。若另一个编辑器修改了工程，旧计划被拒绝，必须重新预览；若目标类型已被其他操作设置，显示无需转换，不打断其控制会话。没有 system.mode 的旧工程显示为数据可视化，读取与打开设置不擅自改写工程。

## 验证

119 项后端测试通过，包括六个有方向的类型转换及完整工程配置保留。最终变更又通过 12 项 Agent 定向测试与源码检查。既有 Chrome 编辑器操作套件通过，覆盖拖动、属性、布线、控制、历史与授权。

独立真实 Chrome + FUXA 浏览器测试通过三类工程新建、服务重启后重开、当前类型显示、AI 生成类型默认值、运行中预览/取消、应用后暂停、输出值不擅改、全部工程对象保留、过时预览拒绝及重新预览、他人已转换时不打断控制、窄窗口操作按钮可见和旧工程兼容。过程只用隔离模拟数据，未操作真实设备。

复现：`npm test`、`npm run check`、`npm run test:browser`。单独重跑类型验收：`node scripts/browser/project-modes.cjs`，可用 FLEXHMI_MODE_ARTIFACTS 指定输出目录。结果、截图和测试源文件 SHA-256 随本文保存。

这些入口已在源码验证，尚未包含在已发布的 0.4.3 安装包中。真实模型生成质量、行业资料适用性和完整产品目标仍需后续验收。
