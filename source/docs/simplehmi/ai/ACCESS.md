# 本机访问保护与 Agent 授权

此功能已包含在 Windows / macOS 0.4.2 安装包中；旧 Windows 0.4.0 / macOS 0.4.1 不包含。默认保持可信本机模式；用户主动启用后，服务端才强制登录和 Agent 授权。

## 在界面启用

1. 打开 AI 工作台 → 连接外部 Agent → 访问保护与 Agent 授权。
2. 设置并确认至少 12 个字符的所有者密码。启用后现有未授权连接失效，自动控制需要重新启动。
3. 选择操作范围、填写 Agent 名称和有效期，创建授权。复制生成的 MCP 配置到对应客户端。
4. 不再使用时点击“撤销”。令牌只在创建时显示一次，之后列表只提供名称、范围、到期日和撤销状态。

令牌适用于本工作区全部工程。最多同时保留 20 个有效授权，接口支持 1–365 天，界面提供 7 / 30 / 90 天。丢失令牌时撤销旧授权并创建新的。

## 服务端范围

| 身份 / 范围 | 允许的操作 |
|---|---|
| 所有者 | 中文编辑器、工程师界面、模型配置、创建与撤销授权、工程与控制 |
| read | 读取工程、实时值、历史、计划、知识、评估和控制状态 |
| engineering | 以上加计划预览/应用/取消、设备连接测试、模型生成与行业评估 |
| full | 以上加经过检查的点位写入、启动和暂停自动控制 |

真实设备写入另需创建 full 授权时勾选许可，且调用仍必须明确声明真实写入及目标。MCP 还需要宿主配置 `FLEXHMI_PHYSICAL_WRITES=1`。修改客户端的范围或 Agent 名称不能扩大服务端许可。

Agent 不能直接调用旧保存、加载、写值接口绕开计划检查，也不能修改模型配置或管理授权。上游工程师 HTTP 接口和 Socket.IO 仅允许所有者；Agent 使用受限的 SimpleHMI 接口。未登录浏览器仍可取得登录页面和公开的最小启动状态。

## HTTP、CLI 与 MCP

HTTP 请求使用 `Authorization: Bearer <授权令牌>`。CLI `scripts/agent-cli.cjs` 和 MCP 均从 `FLEXHMI_TOKEN` 环境变量读取令牌。CLI 的 `SIMPLEHMI_URL`、MCP 的 `FLEXHMI_URL` 仍只接受本机 HTTP(S) 地址，不跟随重定向，不允许在 URL 中夹带凭据。

保护模式下，服务端审计使用经过认证的授权 ID，忽略 Agent 自报的 actor。未启用保护时 actor 仍只是标签；历史记录的 editor / agent / load 表示操作通道。已有历史不会被追认为认证记录。

## 会话、撤销和控制

浏览器所有者使用 HttpOnly、SameSite=Strict Cookie，会话最多 12 小时，只保存在当前进程内。服务重启后需要重新登录。Agent 授权持久化，到期或撤销后拒绝新请求。修改所有者密码需要旧密码，会撤销全部 Agent 授权和旧浏览器会话，并保持当前窗口登录。

排队的保存、计划应用和写入在执行前重查授权；控制执行器在循环和步骤动作间检查会话或令牌。失效后暂停后续自动写入。已发出的设备指令仍可能完成，会保留回读记录，不会自动把设备输出归零或回滚。

## 存储与边界

配置位于后端 `settings.workDir` 下的 `simplehmi/access/policy.json`；访问事件记录在相邻 `events.jsonl`。密码使用带随机盐的 scrypt，随机令牌只保存 SHA-256 摘要。配置通过临时文件替换写入，Unix 目录权限 0700、文件 0600；Windows 仍依赖当前用户目录的系统权限。

不要将带令牌的接入配置提交到仓库或公开日志。损坏的访问配置会阻止启动，不会自动解除保护。没有密码找回接口；需要恢复时应先停止服务、保存工程和访问配置备份，由本机管理员处理，勿直接删除整个数据目录。

当前是单所有者、本机 Agent 授权模型，尚无多人账号、单点登录、按项目权限和远程部署。它不隔离拥有本机文件权限的操作系统用户，也不构成工业安全认证。默认可信本机模式不提供上述身份隔离。

## 已执行验证

隔离真实 FUXA 进程覆盖：匿名请求拒绝、服务端范围、Host / Origin 校验、伪造凭据不能回退、令牌到期与撤销、密码轮换、上游 HTTP / Socket.IO、撤销后控制暂停、排队保存前授权失效。官方 MCP 客户端验证宿主 full 配置不能提升 read 令牌权限；CLI 验证带令牌读取能力。隔离 Chrome 完成启用保护、创建只读授权、拒绝控制、撤销、改密码、退出与重新登录。均使用测试数据，没有替实际用户设置密码。
