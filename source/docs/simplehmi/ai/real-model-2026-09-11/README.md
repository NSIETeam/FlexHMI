## 已修正的产品行为

- 模型设置允许 30–900 秒，默认及旧配置仍为 120 秒；重启保留设置，会话密钥不写盘。
- 运行任务显示实际耗时和本次上限；设置变更仅影响下一任务；取消后计时停止，网络连接中止。
- 复用已有 HTTP 依赖，消除独立的五分钟等待限制；继续限制解压后响应为 2 MB，拒绝重定向及凭据转发。500 系列错误提示服务暂不可用。
- 行业评估保留原有采样后 3 分钟有效期，延长等待不能延长观测有效期。
- ID 冲突提示列出两个冲突位置。对保存的真实首轮输出重放校验，已指出设备/tank_source 与画面/overview/组件/tank_source；这是离线重放，不是新模型调用。
