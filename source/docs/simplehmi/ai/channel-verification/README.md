# 独立管线通道分离验收

2026-09-11。上一轮 11 节点、11 连接的多来源/回流样例有两处共线路径。本轮自动平移内部线段，在不改变设备位置、起止设备、端口和流向的情况下，将两处共线消除；本样例没有新增折角。更新原因进入 AI/Agent 预览诊断。

通道调整会检查画面边界、设备与名称区域、正交方向、端点方向以及独立管线的距离；按连接 ID 固定顺序执行，最多四轮和 1024 个候选。源相同或终点相同的分支保留可共用的干线。无法改进时保留原路径及原有诊断，不虚构可用通道；同端点重复直线仍会提示重叠。算法不改变物理连接、变量或控制行为。
