# SimpleHMI 0.2.0 演示候选版

交付日期：2026-09-10。基于 FUXA v1.3.4，保留工业通信与工程师界面。

## Windows 安装

- Intel / AMD 64 位电脑：`SimpleHMI-0.2.0-Windows-x64-Setup.exe`。
- Windows ARM 电脑：`SimpleHMI-0.2.0-Windows-arm64-Setup.exe`。
- 建议在 Windows 11 上验收。双击安装包，按中文向导完成，启动桌面 SimpleHMI。
- 安装包内含 Electron 44.3.0、Node.js 22.23.2、预构建前端、服务端依赖和对应架构的 SQLite / 串口模块；日常启动不需要下载依赖。
- 默认安装到 `%LOCALAPPDATA%\Programs\SimpleHMI`。工程、数据库和日志保存在 `%APPDATA%\SimpleHMI`；菜单“打开数据目录”可定位。卸载保留工程数据。先导出备份，再升级或更换架构，升级前退出应用。
- 这是未签名安装包，Windows 可能显示未知发布者。请核对随附 SHA-256；本次没有代码签名证书。
- 本次在 macOS 上交叉构建，**尚未在 Windows x64 / ARM64 真机执行安装、运行和卸载验收**。不能将包生成与静态检查通过等同于 Windows 实机验收。

## 新增体验

1. 组件 → 设备图形库：112 种工艺符号，支持名称搜索、八类筛选与常用收藏。仍保留原有 13 种基础/工业/数据组件，以及垃圾焚烧演示专用设备。
2. 缺少外观时，点击“导入 SVG”。支持静态几何、文字和渐变；清理脚本、外部引用等不支持内容。每张最大 128 KB，每个工程最多 16 张自定义图形。自定义图形随工程导出导入，收藏保存在当前浏览器。
3. 图形选择与通信协议独立：112 种图形不是 112 个驱动。Modbus TCP 普通向导可用；RTU、S7、OPC UA 通过工程师模式及原驱动/插件路径接入，仍需相应驱动和现场配置。
4. 图形绑定后显示点位值、单位与数据质量；内置工艺符号可随正值着色。自定义 SVG 当前保留原色，不自动把任意图形变成动画设备。
5. Shift 点击或框选多选；Ctrl+A 选择当前画面可编辑对象。右侧或顶部“对齐”提供六种对齐和水平/垂直等距；等距需要至少三个对象。拖动有网格与参考线吸附，Alt 临时关闭；图层可锁定对象。
6. 统一图标、中文字体回退、标签位置和数值排版；流程管线重排，减少穿过标签；修复属性输入未及时生效、模板覆盖已有工程等问题。

## 验收结果与限制

- 自动化验收 17/17 通过，覆盖实际 FUXA Runtime + 本地 Modbus TCP 从站读写/离线质量、模拟流程、对齐分布和图形库。
- 浏览器实测：三图形多选对齐、等距、属性修改、SVG 导入清理、变量绑定、运行实时值、重载保留图形和绑定。
- 桌面后台独立目录启动、实例随机标识、工作台响应及 IPC 关闭通过。
- 两种架构共 10 个主要 PE 文件检查通过：应用、Node、SQLite、串口、可选 bcrypt。无 SQLite/串口架构混用。可选 bcrypt 若系统没有 VC runtime，Node-RED 原有代码会回退到 bcryptjs；主服务已使用 bcryptjs。
- 尚未连接真实 PLC；历史为当前服务进程的有限缓存；没有生产安全联锁、持久报警审计、多人权限、自动更新或安装包签名。此版用于产品演示和接线联调，不是无人值守生产控制系统。

## Windows 实机验收顺序

1. 离线安装并首次启动；确认不需要额外安装 Node.js。
2. 项目 → 垃圾焚烧发电 → 运行 → 启动流程，查看数值和流向。
3. 新建项目、导入 SVG、添加变量并绑定；关闭应用再打开，检查工程保留。
4. 打开工程师模式；接 Modbus TCP 测试从站，再按 README 寄存器说明接真实 PLC。
5. Windows ARM64 额外检查串口枚举和实际 RTU 适配器；两个平台检查全屏、中文目录、升级、卸载后数据保留。

源代码、架构和真机 Modbus 操作见项目 README。完整产品批判与下一阶段清单见 `PRODUCT-REVIEW.md`。
