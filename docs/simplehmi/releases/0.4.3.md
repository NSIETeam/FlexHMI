# FlexHMI 0.4.3 桌面候选版

当前为待验收候选版本，尚未替换官网下载的 0.4.2。候选计划覆盖 Windows x64 / ARM64、macOS Apple Silicon / Intel；只有对应原生安装及功能验证通过后才发布安装包。

## 本次变化

- 内置 AI 生成步骤流程时附加已验证的资料引用，与外部 Agent 保持一致。
- 资料在步骤执行期间过期时停止后续写入，记录已完成的输出，不错误标记步骤完成。
- 内置 AI 与外部 Agent 的报告和修改建议统一保存；新增评估记录搜索、工程/来源筛选、翻页与重开。
- 无改动报告重启后可找回；打开历史建议时读取关联计划最新状态。
- MCP 增至 24 个工具，新增只读评估记录检索；保留旧工程格式及访问保护。

## 候选验证要求

沿用安装、架构/源码一致性、原生依赖、编辑/运行、单实例、模拟控制、升级、卸载保留数据等检查。新增实际安装后调用内置模型协议入口生成带引用的步骤计划、应用、无改动报告保存、搜索翻页、MCP 只读访问，以及重启后的报告和引用恢复；执行已安装的控制模块检查写入期间资料过期的中止行为。

源码预检已通过上述新增链路。模型响应由本机协议夹具提供，不能据此声称真实模型推理或生产行业资料质量已验收。安装包保持预览属性；签名、公证与实际验证的系统范围将在原生结果确认后记录。
