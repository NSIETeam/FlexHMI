# FlexHMI 0.4.2 桌面预览版

新增无代码步骤控制、普通编辑保存历史与恢复，以及可选的所有者登录和 Agent 授权。Windows 安装菜单统一为桌面版，并修正中文文本编码；全屏仍为可选功能。

四种安装包均已通过各自原生环境的实际安装验收。

| macOS Intel | [FlexHMI-0.4.2-macOS-x64.dmg](https://github.com/NSIETeam/FlexHMI/releases/download/v0.4.2-preview/FlexHMI-0.4.2-macOS-x64.dmg) | 191.1 MB |
| Windows arm64 | [FlexHMI-0.4.2-Windows-arm64-Setup.exe](https://github.com/NSIETeam/FlexHMI/releases/download/v0.4.2-preview/FlexHMI-0.4.2-Windows-arm64-Setup.exe) | 56.3 MB |
| Windows x64 | [FlexHMI-0.4.2-Windows-x64-Setup.exe](https://github.com/NSIETeam/FlexHMI/releases/download/v0.4.2-preview/FlexHMI-0.4.2-Windows-x64-Setup.exe) | 60.2 MB |

已验证：启动与原生模块、编辑/运行画面、守恒供水模拟、工程保存重开、编辑历史恢复、步骤控制两次回读、MCP 服务端权限、撤销后暂停控制、重启保留历史和授权，以及升级和卸载保留工程。Windows 还验证中文名称、旧菜单迁移及保留无关文件。

Windows x64 在 Windows Server 2025、ARM64 在 Windows 11 验证；两种 Mac 均在 macOS 15.7.9 验证。Windows 10 / 11 x64 和 macOS 13/14 尚未直接验证。

预览版没有 Windows 发布者签名或 Apple Developer ID 签名及公证。真实模型服务、物理 PLC 和生产行业知识质量尚未完成验收；内置资料和过程数据用于演示。访问保护默认关闭，启用后需要所有者密码，Agent 使用单独授权。
