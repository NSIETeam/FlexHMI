# FlexHMI 0.4.2 桌面候选版

此版本正在打包验收，尚非官网下载推荐版。当前可用下载仍为 Windows 0.4.0 / macOS 0.4.1。

新增普通编辑保存历史、差异预览和修改前版本恢复；新增待机、供水、停机等可配置步骤流程；新增可选所有者登录和服务端 Agent 范围、到期及撤销。默认可信本机模式，用户主动启用访问保护后才需要登录。

Windows 安装向导、卸载显示名称及开始菜单统一为 FlexHMI 桌面版。安装标识和用户数据路径保留，升级只清理旧版已知快捷方式。全屏是可选功能。Windows x64 / ARM64 与 macOS Apple Silicon / Intel 使用相同版本源码。

候选验收在实际安装的运行环境上检查工程历史恢复、步骤控制两次写入回读、守恒水量、MCP 只读令牌不能提高权限、撤销后控制暂停，以及重启后的工程、历史和授权持久化。另保留原生模块、编辑/运行界面、单实例、升级和卸载保留数据验收。只有相应平台真实运行成功后才记录合格的安装器哈希并公开发布。

预览版未提供 Windows 发布者签名或 Apple Developer ID 签名及公证。真实模型生成质量、生产行业资料、物理 PLC、Windows 10 和 macOS 13/14 尚无本次验收证据。

Windows 候选构建修正：显式按 UTF-8 读取 NSIS 脚本，中文安装菜单已通过检查。原卸载验证只等到主程序消失，可能早于 NSIS 临时卸载进程结束；现等待全部安装文件、已知快捷方式和卸载登记消失，并保存剩余清单，超时仍判失败。参见 [NSIS 临时卸载进程说明](https://nsis.sourceforge.io/When_I_use_ExecWait_uninstaller.exe_it_doesn%27t_wait_for_the_uninstaller)。复验使用同一安装器字节，分别记录产品源码提交与验收脚本提交，不因测试脚本更新伪造产品构建来源。
