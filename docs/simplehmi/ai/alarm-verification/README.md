# 报警状态与连续编辑修复验收

2026-09-11。新拖入的报警不再假设上限为 80。上限缺失、未绑定、数据过期或非数值时，分别显示未配置、等待有效数据或数据无效，不再显示正常。有效数据达到或超过上限时触发；未达到时显示“未触发上限报警”，不等于整个设备运行正常。Bool 可用上限 1；数值阈值须由用户要求或明确的演示假设确定。

允许空阈值作为工程草稿保存、清空和重新加载；非空非法阈值在保存或 Agent 预览时拒绝并定位组件。AI/Agent 预览提示缺少阈值或绑定。报警仅是显示组件，不执行设备控制。

浏览器首轮发现带连接画面连续编辑属性的第二次修改可能丢失：自动布线克隆了组件，使属性输入仍指向旧对象。修复为只替换布线路径，保留组件对象。首轮失败记录保留在 first-browser-failure.log；其后完整复验通过。
