# AI 原生产品目标（持续执行）

用户目标：原生支持 AI 生成和操作整个系统及界面，覆盖数据可视化、可视化驱动的智能控制、拥有行业数据库且由 AI 评估并操作的系统；为大模型/外部 Agent 提供完整操作能力；默认优化设备布局和布线，告知并处理操作的关联影响。用户提供的图标已确定，最终设计风格明确为黑白。新增明确要求：修复自动布线无理由的拐弯和奇怪箭头方向；缩小软件体积，提供工控机版本，替换客户可见的 FUXA 图标，简化完整方案制作。最终品牌名为 FlexHMI。仓库可以开源；另需同风格官网，提供经过验收的安装包下载。
