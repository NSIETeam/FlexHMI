# AI 原生产品目标（持续执行）

用户目标：原生支持 AI 生成和操作整个系统及界面，覆盖数据可视化、可视化驱动的智能控制、拥有行业数据库且由 AI 评估并操作的系统；为大模型/外部 Agent 提供完整操作能力；默认优化设备布局和布线，告知并处理操作的关联影响。用户提供的图标已确定，最终设计风格明确为黑白。新增明确要求：修复自动布线无理由的拐弯和奇怪箭头方向；缩小软件体积，提供工控机版本，替换客户可见的 FUXA 图标，简化完整方案制作。最终品牌名为 FlexHMI。

## 验收要求与证据

以下每一项都必须完成并实证，才能声明整个目标完成。

- [ ] 三种系统模式：向导、配置、持久化、运行行为与模式转换影响。
- [ ] 内置 AI：自然语言生成多页面、设备/点位/连接/规则，结构化输出校验、错误修复、预览、执行、取消；真实模型调用验收。
- [ ] 外部 Agent：能力发现、完整工程 CRUD、点位/设备/资产/页面/连接/规则/知识库操作、实时数据/历史/诊断、稳定版本化协议和可运行适配器。
- [ ] 影响分析：删除和修改的传递依赖、自动修复、阻断项、通信重启/历史影响；不能静默破坏绑定。
- [ ] 并发与恢复：版本冲突、幂等应用、审计、变更历史、崩溃恢复、回滚；不能把过程控制视为可回滚数据库事务。
- [ ] 自动布局：默认规则、拓扑、锁定、边界、标签避让、循环和分支、多页、人工覆盖、可预览及撤销。
- [ ] 自动布线：端口模型、正交路由、障碍避让、移动后重路由、无法布线诊断、连接编辑、运行流向。
- [ ] 智能控制：可配置规则与状态机、质量/时效检查、范围/频率约束、仿真、写入回读、异常中止、人工接管、操作审计；现场安全联锁不由 LLM 替代。
- [ ] 行业数据库：有来源与版本的领域资料/参数/经验条目，导入/搜索/引用/时效，知识与指令隔离，AI 评估证据链和控制策略衔接。
- [ ] 权限与集成：模型配置、凭据保护、代理身份和能力范围、实时控制授权配置；高级工程能力兼容。
- [ ] 产品 UX：三种模式可演示的完整链路、关联影响可读、错误可修复、图标可替换。
- [ ] 验证与交付：端到端浏览器、真实模型、模拟控制、Modbus 测试从站与故障、持久化重启、双架构安装包更新与平台边界文档。

- [ ] 轻量化与工控机：量化体积、Windows x64 / ARM64 无浏览器内核版、编辑/全屏/停止服务入口、离线依赖、升级/卸载与 Windows 实机验收。
- [ ] FlexHMI 品牌：主界面、工程师工作区、图标、启动页、安装包统一；保留开源法律声明及已有工程兼容。
